# AboutMe

Simple static webpage for GitHub Pages.

## Preview

The site entry point is `/index.html`, so the repository can be published directly with GitHub Pages.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch that contains this repository content and keep the folder as **/ (root)**.
5. Save the configuration and wait for GitHub Pages to publish the site.
